Cómo trabajo

Escuchar primero.

  1. Entiendo el negocio antes de proponer nada.Reunión inicial y levantamiento de lo que necesitas.
  2. Defino un alcance claro.Es lo que permite cumplir plazos.
  3. Ves el sistema antes de que exista.Maquetas y prototipos para validar contigo.
  4. Cada entrega es algo que ya se puede usar.Iteraciones cortas bajo metodología Scrum.
  5. Lo ajusto con quienes lo usan todos los días.Feedback real, cambios rápidos.
  6. Después seguimos.Soporte, mejoras y nuevas etapas.

01

Sistema de Progresión Estudiantil (SDPE)

Universidad de Tarapacá

AngularNode.js · TypeScriptPrisma ORMJWTScrum

Sistema de Gestión de Posgrados

Universidad de Tarapacá

Node.jsExpressMySQLBcryptDocker Compose

  • Configuré middlewares para proteger rutas y validar accesos jerárquicos de forma segura.

React · ViteNode.jsExpressAxiosCORS
