Sistema de Progresión Estudiantil (SDPE)

Universidad de Tarapacá

AngularNode.js · TypeScriptPrisma ORMJWTScrum

Sistema de Gestión de Posgrados

Universidad de Tarapacá

Node.jsExpressMySQLBcryptDocker Compose

  • Configuré middlewares para proteger rutas y validar accesos jerárquicos de forma segura.

Arquitectura de microservicios

React · ViteNode.jsExpressAxiosCORS
